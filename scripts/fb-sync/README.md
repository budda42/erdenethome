# Facebook → BAIRDER сайт автомат sync

Отгон Багана Facebook профайлд (https://www.facebook.com/profile.php?id=61593044292253) шинээр
оруулсан зарыг GitHub Pages сайт руу (`data/fb-listings.json` + `site/img/fb/`) нэмнэ.

Хувийн профайлын постыг Facebook API-аар уншиж болдоггүй тул Claude desktop app-ын **хөтчөөр**
(Facebook-д нэвтэрсэн) уншина. Өдөр бүр товлосон ажил (scheduled task) үүнийг хийнэ.

## Алхмууд
1. Хөтчөөр профайлыг нээж `collect.js`-г бүтнээр нь ажиллуулна (javascript_exec).
2. `await __ehScan(15)` → `{done:true}` болтол (шинэ пост үргэлж хамгийн дээр байдаг).
3. `__ehMeta()` → үр дүн файлд хадгалагдана.
4. `python3 scripts/fb-sync/merge.py plan <3-р алхмын файл>` → шинэ постуудын key-ийн JSON жагсаалт.
   Хоосон `[]` бол шинэ зар алга — дуусна.
5. `__ehQueue(<4-р алхмын JSON>)`, дараа нь `await __ehNext()`-г `cur === total` болтол давтана.
6. `python3 scripts/fb-sync/merge.py add <3 ба 5-р алхмын бүх файл>` → шинэ зарууд нэмэгдэнэ.
7. Гарчиг, ангиллыг шалгаж засаад commit + push → GitHub Actions сайтыг 1–2 минутад шинэчилнэ.

Давхардлыг постын жинхэнэ дугаар (`fbPostId`, зургийн "pcb.<id>") болон текстээр шалгадаг
("pfbid…" холбоос нэвтрэх бүрт өөрчлөгддөг тул ашиглахгүй). Зар биш пост алгасагдана: "ХУДАЛДАНА / ЗАРНА / ТҮРЭЭСЛҮҮЛНЭ" гэж бичээгүй бол байр/байшин/газар/өрөө гэх мэт үг
**болон** м², га, давхар, сая гэх мэт тоон мэдээлэл хоёулаа байх ёстой (мэндчилгээ, мэдээ, сурталчилгаа, зөвлөгөө орохгүй).

## Анхаарах
- Desktop app нээлттэй, компьютер асаалттай, хөтөч Facebook-д нэвтэрсэн байх ёстой.
- Facebook "This is taking longer than expected" гэвэл хуудсыг дахин ачаалаад collect.js-г дахин оруулна.
- Ангилал (Орон сууц / Хашаа байшин / Газар / Түрээс / Объект), өрөө, м², давхар, үнийг текстээс
  автоматаар таньдаг. Буруу бол `data/fb-listings.json`-д засаад `npm run pages:data`.
- "ЗАРАГДСАН" гэсэн шинэ постыг алгасна. Facebook-ээс устгасан зарыг сайтаас автоматаар хасахгүй.
