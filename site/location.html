Зүүн талаас зар сонгоно уу.
Нэг товчоор хадгалдаг болгох (GitHub token)

Token байхгүй үед "Хадгалах" дарахад өгөгдөл хуулагдаж, GitHub-ийн засварлах хуудас нээгдэнэ — тэнд бүгдийг сонгоод (Ctrl+A) буулгаж (Ctrl+V) Commit changes дарна. Нэг товчоор хадгалахыг хүсвэл GitHub → Settings → Developer settings → Fine-grained tokens → зөвхөн erdenethome repo, Contents: Read and write эрхтэй token үүсгээд энд оруулна. Token зөвхөн энэ хөтөч дээр хадгалагдана.
